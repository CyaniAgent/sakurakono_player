## 当前阶段说明

- 本仓库目前**完全等同于**上游 PiliPlus 的代码，尚未做任何修改。
- 我们计划在 PiliPlus 的基础上进行重构与扩展，使其成为一个**通用的视频播放器底座**，剥离 B 站特化功能，增强通用性、可定制性和扩展性。
- 如果你现在 clone 或使用，得到的仍是原始 PiliPlus 的功能，**并非**最终 SKF 版本。
- 后续开发进度将在此更新。

---

## 规划中的功能（Roadmap）

> 以下为设想目标，并非已实现功能，将在后续开发中逐步落地。

- [ ] 剥离 B 站业务逻辑，转为通用播放器内核
- [ ] 插件化架构，支持按需加载功能模块
- [ ] 可自定义的 UI 主题系统
- [ ] 更完善的跨平台适配（桌面端、移动端、Web）
- [ ] 统一的播放控制 API
- [ ] 示例应用（Demo App）供开发者参考
- [ ] 完善的文档和接入指南
